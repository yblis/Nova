Serveur Bookstack

Connectez votre instance Bookstack pour enrichir les réponses de l'IA avec votre documentation.

Configuration requise

Créez un API Token dans votre profil Bookstack :

  1. Connectez-vous à votre instance Bookstack
  2. Allez dans votre profil → API Tokens
  3. Créez un nouveau token et copiez le Token ID et le Token Secret

L'URL doit être accessible depuis ce serveur container.

Paramètres avancés

Nombre de pages Bookstack à inclure dans le contexte.

sec

Temps maximum d'attente de la réponse Bookstack.
